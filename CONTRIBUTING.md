# Contributing

Pull requests are welcome, and so are changes made in a fork: please send them back here so every
child using the app gets them.

- By opening a pull request you agree that your contribution is licensed under GPL-3.0-or-later
  with the additional terms in [NOTICE](NOTICE).
- New source files start with the two-line licence header (see any `.kt` file).
- Every user-visible string goes in both English and Croatian.
- Run `./gradlew testDebugUnitTest` before you open the pull request.
- Never commit a recorded "Your turn" session: it is a child's playing.
